Cluster mode

Several Matricxon nodes working together on shared storage. A cluster is one existing Matricxon (the seed, with its chats and users) that grows with fresh installs only — two populated nodes are never merged. Turning it on moves nothing: the checklist below shows what to move or set on your side first.

Admin secret

A shared password that protects the nodes' admin actions (reset, add or remove nodes and voters, pull, delete). pAIring signs those calls with it; a node that has the secret refuses unsigned ones. Chats and read-only calls need no secret.

  • Set it once, here, after the first node works and before you add other nodes. It is sent to every node at once (all must answer), and to each node you add later.
  • Change or remove it the same way (leave it empty to remove).
  • Another pAIring that joins this cluster enters the same secret in its "Join an existing cluster" form; it does not set a new one.
  • Without a secret anyone who can reach a node can reset it or change the cluster, so also keep the nodes on their own network.

Join an existing cluster

Enter the address of any node of the cluster and the cluster id (shown on the Cluster page of the pAIring that set it up). The node must report that id.

First node and shared folders

Folders every node must reach at the same content (a network mount such as NFS). Saving moves no files. With the cluster running, every node picks the new folders up itself and restarts, one after the other within about half a minute (it needs a quorum). The folders must already exist on each node.

Reset cluster

Every node forgets the cluster (its setup, history and node identity) and its own saved chat caches, and restarts as a fresh install; cluster mode goes off, and pAIring forgets the shared folders and cluster settings; the hosts stay in its list as plain remote hosts. Models and shared folders are not touched. Works without a quorum. Each node is listed below as it finishes; one that cannot be reset from here needs scripts/reset_cluster_node.sh run on that machine.
