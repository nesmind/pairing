MCP servers

Connect tool servers (Model Context Protocol, streamable HTTP) so a model can look things up or take actions for the person chatting. Users turn tools on per chat. Use only servers you trust: whatever a tool returns is shown to the model. Header values (such as an API key) are stored encrypted and never shown again.

These settings affect all users, not just your own chats.
