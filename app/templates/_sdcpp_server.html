stable-diffusion.cpp

A light image engine that runs on a plain CPU (no GPU or PyTorch needed). Local lets this app download (a prebuilt release from GitHub) and start/stop its sd-server on this machine; it serves one model at a time — put a model file (.gguf / .safetensors) in its models folder and set its path below. Remote points at external sd-server(s) instead.

No image models yet — download one under Settings > Model > Browse more models (search e.g. "sd-turbo"; image models are detected and installed here automatically).

Up to 120 hosts — load-balanced across whichever is least busy.
